# Stellaris Localizer

## Начало работы

При первом запуске откройте **Настройки → Пути** и укажите расположение папок:

1. **Папка проектов по умолчанию** — место, где будут храниться ваши проекты переводов.
2. **Папка ваших модов** — `Documents\Paradox Interactive\Stellaris\mod`.
3. **Папка модов Steam Workshop** — `steamapps\workshop\content\281990`.
4. **Папка установленной игры** — `steamapps\common\Stellaris`.

После указания путей нажмите **Сохранить**.


## Создание проекта

1. **Выберите мод перевода.** Создайте мод через лаунчер Paradox. После создания он появится в папке `mod` и станет доступен для выбора в списке. Если перевод ещё не создан, установите флажок **«Перевод ещё не создан»**.
2. **Выберите исходный мод**, который хотите перевести.
3. **Укажите предыдущую английскую локализацию** (необязательно). Выберите папку старой версии исходного мода, содержащую каталог `localisation`. Это позволит программе определить изменения между версиями.
4. **Название проекта задаётся автоматически.** При необходимости вы можете изменить его.
5. Нажмите **«Создать проект»** и дождитесь завершения. Обработка крупных модов может занять некоторое время.


## Работа с переводом

### Рабочая область

После создания проекта программа загружает файлы локализации и отображает их в виде карточек. Каждая карточка содержит ключ, оригинальный английский текст (EN) и русский перевод (RU).

- **EN** — исходный текст. Доступен для выделения и копирования, но защищён от изменений.
- **RU** — редактируемый перевод. Нажмите на текст один раз, чтобы начать редактирование.
- **Галочка справа** — статус готовности перевода. Серая означает, что строка требует проверки, зелёная — перевод подтверждён.

После редактирования нажмите на галочку, чтобы подтвердить перевод. Карточка будет считаться готовой и исчезнет из фильтра **«Требуют внимания»**. Подтверждение можно отменить сочетанием `Ctrl + Z`.

### Фильтры

Для удобства работы предусмотрены три фильтра:

1. **Все** — отображает все строки локализации, включая неизменённые.
2. **Требуют внимания** — показывает новые и изменённые строки, перевод которых ещё не подтверждён.
3. **Недоперевод** — помогает находить оставшийся английский текст в русской локализации. Ключи при поиске не учитываются.

### Проводник файлов

В левой панели расположен **Explorer** — проводник файлов локализации проекта.

Индикаторы рядом с файлами позволяют отслеживать готовность перевода. При наведении курсора на галочку или полукруг отображается подробная статистика выбранного файла.

### Просмотр связанных строк

Программа распознаёт ссылки на другие строки локализации в формате `$key$`.

При наведении курсора на такую ссылку появляется подсказка с соответствующим ключом и его текстом. Это позволяет просматривать связанные строки, не переключаясь между файлами.

### Массовый перевод

Для работы с внешними переводчиками предусмотрено копирование и вставка сразу нескольких строк.

1. Выделите нужные карточки и скопируйте их. Программа скопирует только английский текст **без ключей и кавычек**.
2. Переведите полученный текст любым удобным способом.
3. Переведённые строки вставляются в русскую локализацию.
